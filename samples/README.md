# Samples: synthetic only

Every file here is made up for testing. The vehicle, lines, and hours are fictional,
and the VIN field is the placeholder `FAKEVIN0000000000`, which is not a valid VIN.
Nothing here comes from a real shop, customer, insurer, or from MOTOR, CCC, or Mitchell
data or documents. "mitchell-style" and "ccc-style" only label which side of the
comparison a file plays.

Do not add real estimates to this repo.
